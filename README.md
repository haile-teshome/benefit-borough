# Expire

Trackers remind. Advisors suggest. **Expire rescues, in the best order, and does it.**

## Expire Valley (the multiplayer game)

A 3D multiplayer valley grown out of your paperwork: every benefit you're about to lose grows as a paper plant bearing coins. Its pages yellow as their deadline approaches. Harvesting one runs the real Expire action (booking call, transfer) through the Reviewer, and the money goes into your rescued total. Classmates farm next door in real time on **SpacetimeDB**: you see each other walk, chat, and harvest, and you can send surplus dining dollars to a friend's mailbox. Elder Ruth on the village square is the Reviewer: ask her to approve a sunscreen cart on your FSA and she says no.

```bash
# one time: install the SpacetimeDB CLI (https://spacetimedb.com/install), then
npm run valley:server                                       # terminal 1: local SpacetimeDB on :3100
spacetime server add valley --url http://127.0.0.1:3100 --no-fingerprint   # once
npm run valley:publish                                      # publish the world module
npm run dev                                                 # terminal 2: http://localhost:3000/valley
```

Open `http://localhost:3000/valley?farmer=2` in a second window for a second farmer. `npm run valley:reset` wipes the world and every farmer's ledger before a demo.

**Controls:** WASD or click to walk · E to interact · Enter to chat · M to mute.

**Art (all CC0, fetched by `scripts/fetch-assets.sh` into `public/models/`):** hex terrain, buildings, trees and props from the [KayKit Medieval Hexagon Pack](https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0) by Kay Lousberg; animal farmers and Ruth the alpaca from the [Quaternius Ultimate Animated Animal Pack](https://quaternius.com/packs/ultimateanimatedanimals.html). The paper crops, stamps and UI are original.

| Piece | File | Notes |
| --- | --- | --- |
| World module | `valley-server/src/index.ts` | Tables `player`, `plot`, `gift`, `chat`. Reducers `join`, `move`, `plantFarm`, `harvest`, `sendGift`, `openGift`, `say`, `setProfile`. Farmers are created by `join`, never on connect, so the CLI can't spawn ghosts. |

### 3-minute game demo
1. Two laptops (or two windows). Each farmer plants their documents: six crops sprout, priced and wilting by deadline.
2. Walk to the Tooth Lily, press E: "$1,900 becomes $1,550". Harvest: Expire calls Bright Smile Dental live in the dialogue box. +$350, and the other player sees the crop turn to "Rescued".
3. Walk to Elder Ruth. "Spend my FSA on sunscreen?" She refuses, citing rule 2. "Every merchant in this valley profits when you spend. I don't."
4. Harvest the Cafeteria Corn and send $195 to your classmate. A present appears on their mailbox in real time.

Cal Hacks 13.0. Expire reads your benefits summary, dental treatment plan, EOBs, dining statement and card list, finds money that is about to expire, works out the cheapest way to rescue it, and acts (books the appointment, sends the transfer). A Reviewer has to approve every action first.

## Run it

Expire is an iPhone app (Expo, in `mobile/`) backed by this Next.js server, which runs the engine, the Reviewer and the ledger. There's also a web board at http://localhost:3000.

```bash
npm install && npm run dev          # backend + web board on :3000
cd mobile && npm install && npx expo start   # then press i (simulator) or scan the QR with Expo Go
npm test                            # engine math + Reviewer rules
```

The phone finds the backend at the same LAN address Metro serves from, on port 3000. To use a deployed backend instead, set `EXPO_PUBLIC_API_URL`. Your phone and laptop must be on the same Wi-Fi.

If `npx expo start` can't find the simulator, Xcode isn't selected. Run `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer` once, or prefix the command with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.

You don't need any keys. Each integration falls back to a deterministic mock, and a badge in the header shows whether it is **live** or **mock**. To go live, copy `.env.example` to `.env.local` and fill in the keys you have.

## Architecture

```
documents ─▶ Extract (Claude) ─▶ Optimize (calculators + Claude) ─▶ Reviewer (rules + Claude) ─▶ board ─▶ tap ─▶ confirm ─▶ dispatch ─▶ ledger
                │ every claim must quote a verbatim span        │ numbers never come from a model       │ a model can tighten a verdict, never loosen it
```

| Piece | File | Notes |
| --- | --- | --- |
| Mobile app | `mobile/src/app/` | Expo Router: `index.tsx` is the board, `tile/[id].tsx` is the modal with options, Reviewer, booking and sources. |
| Extract | `lib/engine/extract.ts` | Structured output (`claude-opus-5-5`). A claim whose `source_span` isn't verbatim in a document gets dropped. |
| Optimize | `lib/engine/optimize.ts` | Plain functions do the math (dental year-split search, deductible/out-of-pocket window, dining burn rate). Claude only writes the copy, and only when it agrees with the calculator's pick. |
| Reviewer | `lib/engine/reviewer.ts` | The 6 rules from the build plan. Deterministic checks run first, then Claude. Every verdict goes into the audit trail. |
| Ledger + state | `lib/store.ts` | A local JSON stand-in for the Convex tables (`.data/state.json`). Rule 6: the ledger moves only on a confirmed action. |
| Booking call | `lib/integrations/cartesia.ts` | Cartesia TTS voices the agent line when `CARTESIA_API_KEY` and `CARTESIA_VOICE_ID` are set; otherwise it runs a scripted call. |
| Transfer | `lib/integrations/transfer.ts` | Capital One Nessie transfer when the `NESSIE_*` keys are set; otherwise a simulated x402 settlement. |

## Demo script (numbers come from `lib/documents.ts`)

1. Scan the 5 sample documents. The board shows **$2,287 at stake** in the next 68 days.
2. Medical tile: Dr. Patel already ordered the MRI. Before Jan 1 it costs **$360**; in January, **$1,800**. Saves $1,440.
3. Dental tile: the treatment plan costs **$1,900** if done all this year. Moving one crown to January makes it **$1,550**. Tap Book, confirm, watch the call, and the ledger goes up $350.
4. FSA tile: $612 is under the $640 carryover limit, so nothing is forfeiting. Ask the Reviewer about a sunscreen cart and it **rejects on rule 2**.
5. Dining tile: at $29.50/week you'll spend about $215 by Dec 14. Send the $195 surplus to a classmate.
